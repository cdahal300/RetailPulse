# Product Non-Goals

- NGL-001: Build a payment processor, acquirer, terminal certification program, or settlement system.
- NGL-002: Store or process PAN, CVV, PIN, magnetic-stripe data, or raw card data.
- NGL-003: Make cloud availability a prerequisite for checkout.
- NGL-004: Let the manager or owner PWA control checkout or payment terminals.
- NGL-005: Support arbitrary offline refunds in the first release.
- NGL-006: Replace a fiscal, tax, loyalty, or CRM system without an explicit decision.
- NGL-007: Use AI to approve payments, set prices, mutate inventory, or block checkout.
- NGL-008: Build a native mobile application before required device capabilities justify it.
