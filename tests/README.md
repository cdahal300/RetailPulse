# Test layout

- `Unit/`: fast domain and application tests
- `Integration/`: PostgreSQL, SQLite, Service Bus, Blob, and provider-adapter tests
- `Contract/`: versioned API and event compatibility tests
- `EndToEnd/`: user workflows across POS, sync, cloud, and dashboards
- `Pwa/`: Playwright and browser tests for the manager and owner PWA
- `Pwa/fixtures/`: authenticated roles, stores, feature-flag states, and responsive device profiles
- `Fixtures/`: deterministic data builders and test environments
